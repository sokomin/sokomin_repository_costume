赤石の民衆 秘奥コスチューム素材リポジトリ

このリポジトリは 赤石の民衆 (sokomin.github.io) で公開している RED STONE のキャラクターコスチューム画像・GIF アセットを保管しています。 GitHub Pages 経由で https://sokomin.github.io/sokomin_repository_costume/... として配信されます。

収録範囲

  • 秘奥コスチューム: 強化前と強化後の 2 形態を持つコスチューム
  • 各コスチュームは 最大 2 形態 × 11 色 のバリエーションを収録

2 形態を持たない通常コスチュームは別リポ sokomin_repository_costume2024 に保管しています。

ファイル命名規約

costume/
├── <name>_s1.png             # 強化前 デフォルト色 静止画
├── <name>_s1_idle.gif         # 強化前 デフォルト色 立ちアニメ
├── <name>_s1_pal01.png        # 強化前 色違い (pal01〜pal10)
├── <name>_s1_pal01_idle.gif
├── ...
├── <name>_s2.png             # 強化後 デフォルト色
├── <name>_s2_idle.gif
└── <name>_s2_pal10_idle.gif   # 強化後 色違い
  • _s1 / _s2 = 強化前 / 強化後
  • _pal01〜_pal10 = 色違いバリエ (デフォルト色はサフィックス無し)
  • .png = 静止画 / _idle.gif = 立ちポーズアニメ
